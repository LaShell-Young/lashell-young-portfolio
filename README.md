# lashell-young-portfolio

A resume portfolio built with React, MUI, and Vite.

## Local development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it locally with
`npm run preview`.

## GitHub Pages deployment

The GitHub Actions workflow builds both pages and deploys the `dist/` output
when changes are pushed to `main`. In the repository settings, set **Pages >
Build and deployment > Source** to **GitHub Actions**.
